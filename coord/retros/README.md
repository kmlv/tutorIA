# Retros

Retros are optional. Use them after coordination-heavy or multi-day tasks to
record what flowed, what cost time, and what should change next time.

Do not create retros as ceremony after every small task.

Use `coord/templates/retro.md` when the task involved multiple active agents,
missed handoffs, repeated principal correction, review churn, or protocol rules
that should be internalized for future work.

If a retro changes a durable hypothesis about an agent's strengths,
preferences, or coordination habits, update `coord/PROFILES.md` from the retro
and link back to the source.

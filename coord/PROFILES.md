Last updated UTC: 2026-08-10T16:44:23Z

## Working hypotheses

Profiles are working hypotheses — update them from retros, not vibes; supersede a
bootstrap hypothesis after ~3 retros.

Use this file to capture durable observations about how agents work in this
project. Each agent section uses:

- Strengths
- Current preferences
- Learning notes

Update profile entries only from a finalized retro, a documented review or
handoff pattern, or Kristian's explicit correction. Link the source retro,
thread, review, or decision when adding a learning note.

Active wake-prompt notes use the same source-tagged shape as lessons:

- [priority:2] [status:active] [source:path:line] [confidence:high|medium|low] [ttl:30d|last-confirmed:YYYY-MM-DD] Durable observation.

If the optional task-management ledger is installed, use `coord/retros/` and
`coord/templates/retro.md` as the normal evidence path for profile changes.
